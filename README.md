# mnltEngine - Graphics/Physics Engine

## Overview

**mnltEngine** is a simple graphics and physics engine developed in C++ using Vulkan. It features a particle life simulator, a solar system simulator, and model loading capabilities. The inspiration for creating this engine came from a video featuring the [Particle Life](https://github.com/hunar4321/particle-life) project.

## Features

- **Particle Life Simulator:** Simulate the lifecycle and behavior of particles with customizable properties.
- **Solar System Simulator:** Explore a dynamic simulation of a solar system, complete with orbiting planets and realistic lighting effects.
- **Model Loading:** Load and render 3D models with support for various file formats, allowing for versatile visualization.

## Installation

To build and run `mnltEngine`, follow these steps:

1. Clone the repository:
   ```bash
   git clone https://github.com/AbdallahAE/mnltEngine.git
   cd mnltEngine
   ./build.sh
2. Ensure you have the following libraries installed:
   - GLFW
   - Vulkan SDK
   - GLM

4. Note: This engine has only been tested on Linux.
